# league-stats

## JSON files in data/

The files `items.json`, `setData.json`, and `sets.json` are portions of a larger JSON file found at [Community Dragon](https://raw.communitydragon.org/latest/cdragon/tft/en_us.json). These files contain information that allow us to quickly and easily find relevant images and other related content. I have chosen to separate them both for ease of use and get around tokenization limits within Visual Studio Code. They only cover the US English locale, but Community Dragon also has other locale files if needed.
